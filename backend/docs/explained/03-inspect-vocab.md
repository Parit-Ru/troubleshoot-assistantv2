# ขั้น 1.2.1 — สำรวจตารางคำศัพท์ก่อนตัด

## 1. ทำไมต้องตัดคำศัพท์

ขั้น 1.1 วัดได้ว่าโมเดลใช้หน่วยความจำสูงสุดราว 440–456 MB เกินงบของ Render free (512 MB รวม NestJS) และการปรับค่าตั้งของ ONNX Runtime 4 แบบไม่ช่วยเลย

โมเดล `paraphrase-multilingual-MiniLM-L12-v2` รองรับ 50+ ภาษา จึงมีตารางคำศัพท์ 250,002 token × 384 มิติ ซึ่งเป็นส่วนใหญ่ของโมเดล แต่ระบบเราใช้แค่ภาษาไทยกับอังกฤษ ถ้าตัดแถวของ token ที่ไม่มีวันถูกใช้ออก โมเดลจะเล็กลงโดยผลลัพธ์ไม่เปลี่ยน

## 2. ทำไมผลลัพธ์จึงไม่เปลี่ยน

ตัวตัดคำ (Unigram tokenizer) เลือกได้เฉพาะ token ที่เป็นส่วนหนึ่งของข้อความ

กฎที่ใช้: **เก็บ token ที่ทุกตัวอักษรอยู่ในชุดที่อนุญาต** คือ ASCII, อักษรไทย, `▁` (สัญลักษณ์ขึ้นต้นคำ), สัญลักษณ์ Latin-1 เช่น ° และเครื่องหมายวรรคตอน เช่น “ ” …

ถ้าข้อความมีแต่ตัวอักษรในชุดนี้ token ที่มีตัวอักษรอื่นย่อมไม่มีทางถูกเลือก การตัดคำจึงเหมือนเดิมทุกประการ และได้เวกเตอร์เท่าเดิม ข้อนี้จะพิสูจน์ด้วยตัวเลขในขั้น 1.2.3

ข้อแลกเปลี่ยน: ตัวอักษรนอกชุด เช่น é หรืออีโมจิ จะกลายเป็น token "ไม่รู้จัก" (`<unk>`)

## 3. สคริปต์นี้ทำอะไร (อ่านอย่างเดียว ไม่แก้ไฟล์ใดๆ)

| ส่วน | ตอบคำถาม |
|---|---|
| 1. ไฟล์ ONNX | ตารางคำศัพท์ชื่ออะไร เก็บเป็นชนิดไหน (int8/uint8/float32) ใหญ่เท่าไร และ node ไหนใช้มัน — บอกว่าขั้นถัดไปต้องแก้ตรงไหน |
| 2. ตัวตัดคำ | token แต่ละกลุ่มมีกี่ตัว ตามกฎจะเก็บกี่ตัว ตัวอย่าง token ที่ถูกตัด |
| 3. ข้อความจริง | ข้อความตัวแทน 36 ข้อความ + คำค้นตัวอย่าง 7 ข้อ ใช้แต่ token ที่ถูกเก็บจริงไหม |
| 4. ประมาณการ | ตารางจะเล็กลงเท่าไร ทั้งในไฟล์และถ้าอยู่ในหน่วยความจำแบบ float32 |

## 4. วิธีรัน

ยืนที่ **รากของ repo** (ไม่ใช่ `backend/`) เพราะสคริปต์ Python ทุกตัวของโครงงานอยู่ที่ `scripts/` ของราก

```powershell
pip install onnx==1.17.0
python scripts/inspect_vocab.py
```

- ใช้ Python ที่มี `tokenizers` อยู่แล้วเพราะติดมากับ `transformers` (โครงงานนี้ไม่มีโมเดลที่เทรนเองแล้ว สคริปต์ในโฟลเดอร์ `scripts/` ที่เกี่ยวกับการค้นหาอาการใช้โมเดลสำเร็จรูปเท่านั้น)
- `onnx==1.17.0` มีไฟล์ติดตั้งสำเร็จรูปสำหรับ Python 3.12 บน Windows และใช้ร่วมกับ `numpy==1.26.4` ที่ล็อกไว้ได้
- ต้องมีไฟล์โมเดลใน `backend/model-cache/` จากขั้น 1.1 แล้ว

## 5. วิธีอ่านผล

- **ส่วนที่ 1:** ถ้าไม่พบตารางคำศัพท์ แปลว่าโมเดลเก็บแบบที่คาดไม่ถึง ต้องหาวิธีอื่น
- **ส่วนที่ 2:** "เก็บไว้ X%" ยิ่งน้อยยิ่งลดหน่วยความจำได้มาก
- **ส่วนที่ 3:** ต้องได้ "มีปัญหา 0" ถ้าไม่ใช่ แปลว่ากฎตัดตัวอักษรที่ระบบต้องใช้ ต้องแก้กฎก่อน
- **ส่วนที่ 4:** ค่าประมาณเท่านั้น ตัวเลขจริงวัดในขั้น 1.2.4
