# frontend/.gitignore

## 1. หน้าที่ของไฟล์

บอก git ว่าไฟล์/โฟลเดอร์ไหนใน `frontend/` ไม่ต้องติดตาม (แม่แบบมาตรฐานของ Vite)

- **ใครเรียกใช้**: git ; **เรียกใช้**: ไม่มี

## 2. อธิบายทีละบล็อก

| บรรทัด | รายการ | ความหมาย |
|---|---|---|
| 1–8 | `logs`, `*.log`, `npm-debug.log*`, `yarn-*`, `pnpm-debug.log*`, `lerna-debug.log*` | ไฟล์ log |
| 10–12 | `node_modules`, `dist`, `dist-ssr` | แพ็กเกจและผล build |
| 13 | `*.local` | ไฟล์ตัวแปรสภาพแวดล้อมเฉพาะเครื่อง เช่น `.env.local`, `.env.development.local` |
| 15–24 | `.vscode/*` (ยกเว้น `extensions.json`), `.idea`, `.DS_Store`, `*.suo`, `*.ntvs*`, `*.njsproj`, `*.sln`, `*.sw?` | ไฟล์ของ editor/ระบบ |

## 3. การส่งข้อมูล

ไม่มี

## 4. จุดที่ควรระวัง

- **`.env.development` และ `.env.production` ไม่ถูก ignore** (ตั้งใจ — ไม่มีความลับ ตามคอมเมนต์ในไฟล์เหล่านั้น) ต่างจาก `.env`, `.env.local` ของ backend ; ส่วนไฟล์ที่ลงท้าย `.local` ถูก ignore จึงเหมาะกับการใส่ค่าเฉพาะเครื่อง
