# frontend/src/pages/NotFoundPage.tsx

## 1. หน้าที่ของไฟล์

หน้าที่แสดงเมื่อเปิด URL ที่ไม่มีอยู่ในแอป (พิมพ์ผิด หรือลิงก์เก่า) : แสดงพาธที่เปิดมา และลิงก์กลับหน้าแรก/หน้าเลือกอาการ
หน้านี้ **ไม่ใช่** หน้าที่แสดงตอนหา session ไม่เจอ — กรณีนั้น URL ถูกต้องแต่เซิร์ฟเวอร์ตอบ `SESSION_NOT_FOUND` ซึ่ง `SessionPage` จัดการเอง

- **ใครเรียกใช้**: `App.tsx` (route `path="*"` วางเป็นเส้นสุดท้าย)
- **เรียกใช้**: `Link`, `useLocation` (react-router-dom), `Icon`

## 2. อธิบายทีละบล็อก

`NotFoundPage()` (13–35): `pathname = useLocation().pathname` (ส่วนหลัง `#` เช่น `/sympotms`) ; วางไอคอน `warning`, `<h1>` "ไม่พบหน้านี้", ข้อความ "ไม่มีหน้า {pathname} ในระบบ ลิงก์อาจพิมพ์ผิดหรือเลิกใช้แล้ว" (`pathname` ใน `<code className="break-all">`), ลิงก์ "กลับหน้าแรก" (`/`) และ "ไปหน้าเลือกอาการ" (`/symptoms`)

## 3. การส่งข้อมูล

อ่าน `pathname` จาก router แล้วแสดงเป็นข้อความ (React escape ให้อัตโนมัติ)

## 4. จุดที่ควรระวัง

- เนื่องจากใช้ `HashRouter` `pathname` คือส่วนหลัง `#` ไม่ใช่พาธจริงของเซิร์ฟเวอร์
- `pathname` แสดงเป็นข้อความธรรมดา ไม่มีช่องโหว่ XSS เพราะ React ไม่ตีความเป็น HTML
