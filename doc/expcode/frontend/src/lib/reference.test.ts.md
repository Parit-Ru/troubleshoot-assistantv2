# frontend/src/lib/reference.test.ts

## 1. หน้าที่ของไฟล์

ไฟล์ทดสอบ (Vitest) ของ `formatPages` และ `formatSourceLine` ใช้ที่มาจริงของสถานะหน้า 43 ในคู่มือแอร์ AR70H (`RAC255-00_IB_26Y_AR80H_WindFree_GEO_CB_EN-WEB_251229-D04`)

- **ใครเรียกใช้**: Vitest ; **เรียกใช้**: `./reference`, type `NodeReference`

## 2. อธิบายทีละบล็อก (4 เทส)

| บรรทัด | สิ่งที่ยืนยัน |
|---|---|
| 11–19 | `formatPages([43,43])` = `หน้า 43` ; `[43,44]` = `หน้า 43–44` (ใช้ en dash ไม่ใช่ hyphen) |
| 21–32 | ไม่ส่งชื่อคู่มือ → `ที่มาของขั้นตอนนี้: RAC255-…-D04 หน้า 43` ; ส่ง `'Samsung AR70H**D1***'` → `ที่มาของขั้นตอนนี้: คู่มือ Samsung AR70H**D1*** หน้า 43` |
