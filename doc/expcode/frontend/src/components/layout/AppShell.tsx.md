# frontend/src/components/layout/AppShell.tsx

## 1. หน้าที่ของไฟล์

โครงของทุกหน้า : แถบนำทาง (aside) + แถบ "โหมดจำลอง" (เฉพาะเมื่อเปิด mock) + พื้นที่เนื้อหา ใช้ markup ชุดเดียวทั้งมือถือและจอใหญ่ ปรับรูปด้วยคลาส `md:` (≥ 768px) — มือถือ: แถบนำทางเป็นแถบแนวนอนด้านบน ; จอใหญ่: เป็น sidebar ซ้ายสูงเต็มจอ (เลือกแบบนี้แทนเขียนสองชุดแล้วซ่อนชุดหนึ่ง เพราะเมนูมีที่เดียว แก้ที่เดียว)

- **ใครเรียกใช้**: `App.tsx` (ห่อ `<Routes>`)
- **เรียกใช้**: `NavLink` (react-router-dom), `Icon`, `ServerStatus`

## 2. อธิบายทีละบล็อก

- `APP_NAME = 'FixStep'` (21): คอมเมนต์ 16–19 บันทึกว่าเดิมชื่อ FixBot ซึ่งซ้ำกับผลิตภัณฑ์ของ iFixit จึงเปลี่ยนเป็น FixStep (4 ต.ค. 2569) ค้นเว็บแล้วไม่พบผลิตภัณฑ์ชื่อนี้ แต่ยังไม่ได้ตรวจเครื่องหมายการค้า/ชื่อโดเมน ; ตอนเปลี่ยนอีกต้องแก้ทั้งบรรทัดนี้และ `<title>` ใน `index.html`
- `IS_MOCK = import.meta.env.VITE_USE_MOCK === 'true'` (24): อ่านครั้งเดียวระดับโมดูล ใช้ทั้งแถบโหมดจำลองและการซ่อนป้ายสถานะบนมือถือ
- `NAV_ITEMS` (27–30): "หน้าแรก" (`/`) และ "เลือกอาการ" (`/symptoms`) — หน้าตรวจอาการไม่อยู่ในเมนู เพราะเข้าจากลิงก์ในหน้าอื่น
- `NAV_ACTIVE` / `NAV_IDLE` (33–34): คลาสเมนูตอนเลือก/ไม่เลือก (เขียนเต็ม)
- `AppShell({ children })` (40–95):
  - `<aside>` : โลโก้ `NavLink to="/"` + ไอคอน `logo` + ชื่อ ; `<nav aria-label="เมนูหลัก">` วน `NAV_ITEMS` เป็น `NavLink ... end` (`end` กัน `/` ถูกนับว่าเลือกอยู่ทุกหน้า) ; กล่อง `ServerStatus` (`md:mt-auto` ดันไปล่างสุดของ sidebar ; ในโหมดจำลองซ่อนบนมือถือเพราะแถบสีฟ้าบอกเรื่องเดียวกันอยู่แล้ว ซ่อนที่กล่องไม่ใช่ที่ `ServerStatus` เพราะกล่องว่างยังกินระยะ gap)
  - คอลัมน์เนื้อหา : แถบโหมดจำลอง (`IS_MOCK`) "โหมดจำลอง — ขั้นตอนทำงานในเบราว์เซอร์นี้ ยังไม่ได้เชื่อมกับเซิร์ฟเวอร์จริง" อยู่บนสุดของคอลัมน์เนื้อหา (ไม่ใช่เหนือทั้งหน้า เพราะ sidebar สูงเต็มจอจะล้นจอ) ; `<main>` ครอบ `max-w-3xl`

## 3. การส่งข้อมูล

รับ `children` (ผลของ `<Routes>`) แล้ววางใน `<main>` ; `NavLink` เปลี่ยน hash ของ URL (`/#/symptoms`)

## 4. จุดที่ควรระวัง

- ชื่อแอปในหน้าจอ (FixStep) ต่างจากชื่อ "FixBot" ใน backend (`main.ts`, `health.controller.ts`, `package.json`) และ "fixgraph" ใน `package.json` ราก — ชื่อไม่สอดคล้องทั้งโปรเจกต์
- `IS_MOCK` ใช้ที่นี่ต่างจากคำเตือนใน `traversal.ts` เรื่องการเขียนเงื่อนไขตรงๆ เพราะไฟล์นี้ไม่ได้ import mock จึงไม่กระทบการตัดโค้ด (อนุมานจากโค้ด)
- ผูกกับ `ServerStatus` ที่เรียก `/health` เมื่อไม่ใช่โหมดจำลอง
