# frontend/src/components/SlowServerNotice.tsx

## 1. หน้าที่ของไฟล์

กล่องข้อความสีฟ้าบอกผู้ใช้ว่า "เซิร์ฟเวอร์กำลังเริ่มทำงาน — ถ้าไม่มีคนใช้มาสักพัก เซิร์ฟเวอร์ต้องตื่นก่อน อาจใช้เวลาสักครู่" แสดงเมื่อ `useSlowWait` คืน `true` (รอเกิน 4 วินาที)

- **ใครเรียกใช้**: `pages/SessionPage.tsx`, `pages/SymptomsPage.tsx`
- **เรียกใช้**: `Notice` (`tone="info"`)

## 2. อธิบายทีละบล็อก

`SlowServerNotice()` (4–10) : คืน `<Notice tone="info" title="เซิร์ฟเวอร์กำลังเริ่มทำงาน">…</Notice>` — ไม่มี props / state

## 3. การส่งข้อมูล

ไม่มี : หน้าที่เรียกตัดสินว่าจะแสดงหรือไม่ด้วย `useSlowWait(isLoading)`

## 4. จุดที่ควรระวัง

- ข้อความอ้างถึงการที่เซิร์ฟเวอร์ "ตื่น" (ลักษณะของ Render แผนฟรี) หากย้ายไปโฮสต์ที่ไม่หลับ ข้อความนี้จะไม่ตรงกับสถานการณ์
- ไม่มี `role="status"` ในกล่อง ผู้ใช้ screen reader อาจไม่ได้ยินข้อความเมื่อปรากฏ (ดู `Notice.tsx`)
