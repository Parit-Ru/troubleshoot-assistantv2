# frontend/src/components/step/PathRail.tsx

## 1. หน้าที่ของไฟล์

"เส้นทางการตรวจ" : เส้นแนวตั้งทางซ้ายที่ร้อยขั้นที่ผ่านมาแล้วทั้งหมดเข้ากับขั้นปัจจุบัน (ส่วนที่ดีไซน์ตั้งใจให้เด่นที่สุด) แต่ละขั้นที่ผ่านแสดง "ข้อความของสถานะ" (ตัดที่ 2 บรรทัด) กับ "สิ่งที่ผู้ใช้ทำ" ส่วนขั้นปัจจุบันแสดงกล่องขั้นตอน (`children`) แสดงผลอย่างเดียว ไม่มีปุ่ม กดรายการเก่าไม่ได้ ไม่มีทางย้อนกลับ เพราะเครื่องสถานะไม่มีคำสั่งย้อน

- **ใครเรียกใช้**: `pages/SessionPage.tsx`, `pages/HomePage.tsx` (ภาพตัวอย่าง)
- **เรียกใช้**: `Icon`, type `OutcomeKind`, `RenderedNode`, `TrailEntry`, `TrailMarker`

## 2. อธิบายทีละบล็อก

- คอมเมนต์การจัดวาง (6–21): คอลัมน์ซ้าย `w-6` (24px) เก็บเส้นและสัญลักษณ์ ศูนย์กลาง 12px ; เส้นแบ่งเป็นท่อนละรายการ ใช้ `padding` (`pb-6`) ไม่ใช้ margin เพื่อไม่ให้เส้นขาด ; สัญลักษณ์มีพื้น `bg-canvas` ทับเส้นด้านหลัง
- `PathRailProps` (23–29): `entries: TrailEntry[]`, `current: RenderedNode`, `children`
- `OUTCOME_MARKER_CLASSES` (32–37): สีของสี่เหลี่ยมที่สถานะสิ้นสุด (success/info/accent/accent)
- `LINE_CLASSES`, `MARKER_BOX_CLASSES` (39–42)
- `PastMarker` (45–50): `switch-off` → ไอคอนสวิตช์ปิด (ขั้นที่ยืนยันคำเตือนแล้ว) ; อื่นๆ → วงกลมกลวง
- `CurrentMarker` (58–68): สถานะสิ้นสุด → สี่เหลี่ยมเล็กสีตาม `outcomeKind` (ไม่มี → ถือเป็น `handoff_unknown`) ; `requiresSafetyConfirmation` → ไอคอน `switch-on` สีแดง ; อื่นๆ → วงกลมทึบสีหลัก
- `PathRail` (70–113): `<ol aria-label="เส้นทางการตรวจ">` ; วน `entries` เป็น `<li key={`${index}-${entry.nodeId}`}>` — **key ใช้ลำดับประกอบด้วย** เพราะ `nodeId` ซ้ำได้ (เช่น กรอกรหัสผิดแล้ววนกลับ `n_record_code` สองรอบ) รายการเติมต่อท้ายอย่างเดียว ลำดับจึงไม่เปลี่ยน ; ท่อนแรกเริ่มที่จุดไม่ให้เส้นโผล่เหนือจุดแรก ; `<li aria-current="step">` สุดท้ายเป็นขั้นปัจจุบัน วาง `children` และท่อนเชื่อมลงจากรายการก่อนหน้า

## 3. การส่งข้อมูล

`SessionPage` เก็บ `entries` (จาก `toTrailEntry`) + `current` (จาก `SessionResponse.node`) + `<StepView/>` เป็น children → `PathRail` วาด

## 4. จุดที่ควรระวัง

- ค่าตำแหน่ง/ขนาดแบบพิกเซล (`top-5`, `md:top-6`, `h-6`, `md:h-7`) ผูกกับความสูงของ `StepCard` และป้ายชนิด — แก้ padding ของ `StepCard` แล้วจุดปัจจุบันอาจเลื่อนไม่ตรงบรรทัด
- รายการที่ผ่านแล้วหายเมื่อ F5 (เก็บเฉพาะในหน่วยความจำของหน้า ตาม `lib/trail.ts`)
- ใช้ `line-clamp-2` ซึ่งต้องรองรับใน Tailwind v3.3+ (เวอร์ชันที่ใช้คือ ^3.4.19)
