# frontend/src/components/EquipmentPanel.tsx

## 1. หน้าที่ของไฟล์

แผง "อุปกรณ์ที่อาจต้องใช้" ในหน้าตรวจอาการ รายการผูกกับ "ประเภทเครื่อง" ไม่ผูกกับอาการ (ทุกอาการของแอร์ได้รายการเดียวกัน) หัวข้อจึงเขียนบอกตรงๆ กันผู้ใช้เข้าใจว่าต้องใช้ครบทุกชิ้น ทุกชิ้นบอกที่มาเสมอ : มี `sourcePage` → "คู่มือหน้า N" ; ไม่มีแต่มี `authorNote` → "ผู้พัฒนาแนะนำเพิ่ม" (ตามหลักว่าห้ามอ้างว่าคู่มือพูดสิ่งที่ไม่ได้พูด)
**การพับ**: มือถือพับเป็นปุ่มแถวเดียว (ถ้ากาง 7 รายการคำถามแรกจะถูกดันออกนอกจอ) ; จอ `md` ขึ้นไปกางเสมอ ใช้คลาส `md:hidden`/`md:block` สลับ ไม่ต้องตรวจขนาดจอด้วย JS

- **ใครเรียกใช้**: `pages/SessionPage.tsx`
- **เรียกใช้**: `DEVICE_CATEGORY_LABELS` (`lib/labels`), `Icon`, type `DeviceCategory`/`EquipmentItem`, `useId`, `useState`

## 2. อธิบายทีละบล็อก

- props (22–27): `items?: EquipmentItem[]` (ไม่มี/ว่าง = ซ่อนทั้งแผง), `deviceCategory?`
- `EquipmentSource` (30–50): แสดง "คู่มือหน้า {sourcePage}" (ไอคอน book) หรือ "ผู้พัฒนาแนะนำเพิ่ม" (ไอคอน pencil) ; ถ้าไม่มีทั้งคู่ คืน `null` (ไม่เดาที่มาให้)
- `EquipmentPanel` (52–107): `isOpen` state เริ่ม `false` ; `listId = useId()` ผูก `aria-controls` ; ถ้า `items` ไม่มี/ว่าง → `null` ; `title` = "อุปกรณ์ที่อาจต้องใช้" (+ "กับ" + ชื่อประเภทเครื่องเป็นไทยเมื่อรู้ประเภท) ; ปุ่มพับ (`md:hidden`, `aria-expanded`, `aria-controls`) แสดงจำนวนรายการและ "แสดง/ซ่อน" ; หัวข้อ `<h2 className="hidden … md:flex">` สำหรับจอใหญ่ ; รายการใน `div#listId` (`isOpen ? 'block' : 'hidden'` + `md:block`) พร้อมข้อความ "รายการเดียวกันสำหรับทุกอาการของเครื่องประเภทนี้" ; `<ul>` ตาราง 2 คอลัมน์บนจอ `md` ; แต่ละ `<li key={item.equipmentId}>` มีชื่อ, จุดประสงค์, ที่มา

## 3. การส่งข้อมูล

`SessionResponse.equipment` (จาก `EquipmentRepository`) + `deviceCategory` จาก `GraphSummary` → props → วาดรายการ ; state พับ/กางอยู่ในคอมโพเนนต์

## 4. จุดที่ควรระวัง

- หัวข้อสำหรับจอใหญ่เป็น `<h2>` ขณะที่ `StepCard` ก็ใช้ `<h2>` สำหรับข้อความหลักของสถานะ (ลำดับหัวข้ออาจซ้ำระดับกัน) (อนุมานจากโค้ด)
- ข้อมูลอุปกรณ์ในปัจจุบันมีแต่ของแอร์ (7 รายการ) ประเภทอื่นจะไม่เห็นแผงนี้
- ไม่ได้ตรวจว่า `items` มีที่มาครบ — พึ่งสัญญาจากเซิร์ฟเวอร์ (ตาราง `equipment_usage` มี CHECK)
